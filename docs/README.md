# Docs Layout

- `docs/product/`: active product/design docs
- `docs/publishing/`: release and distribution docs
- `docs/archive/`: older roadmap/research material
- `docs/sprite.md`: canonical sprite system doc (kept at this stable path)

## Naming Convention

- Use lowercase `snake_case` for docs filenames and folders.
- Keep root ecosystem-standard names unchanged (`README.md`, `AGENTS.md`, `Cargo.toml`, etc.).
